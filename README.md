# Transmogrifying Vibe Code

An 11 chapter field report on building software with LLMs, outgrowing early architectures, and turning the resulting code into maintainable systems. It follows one developer's return to programming through the creation of PlanStan, from product vision and rapid iteration to architectural debt, library extraction, and practical guidance for other vibe coders.
